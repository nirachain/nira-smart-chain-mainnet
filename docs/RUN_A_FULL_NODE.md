# Run a Nira full node

This procedure is intentionally gated until the Nira mainnet release artifacts exist.

1. Obtain the approved client binary from a signed release and verify its checksum.
2. Obtain the finalized genesis from the same release and verify its published hash.
3. Initialize a new datadir using the client’s documented command:

   ```bash
   geth --datadir /var/lib/nira init network/genesis.json
   ```

4. Start using the reviewed configuration generated by the exact client release.
5. Verify chain ID, genesis hash, peer connectivity, sync status, block height, and logs.

Do not connect a validator wallet or expose RPC until the network launch team approves the deployment.
